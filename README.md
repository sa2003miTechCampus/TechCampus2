# المحلل الحلال — Halal Stocks Analyzer

منصة احترافية لتحليل الأسهم الأمريكية المتوافقة مع الشريعة الإسلامية: فرز شرعي آلي،
تحليل فني وأساسي، توصيات شراء/بيع، أفضل توصيات يومية، وتحليل فوري عند البحث عن أي سهم.

> ⚠️ **إخلاء مسؤولية**: هذا التطبيق أداة تعليمية/بحثية آلية. ليست فتوى شرعية ولا استشارة
> مالية مرخّصة. راجع دائماً هيئة شرعية معتمدة ومستشاراً مالياً مرخّصاً قبل الاستثمار.

## المزايا

- **فرز شرعي آلي** بمنهجية مبنية على معايير AAOIFI / مؤشرات الأسهم الإسلامية (Dow Jones
  Islamic Market، S&P Shariah): فرز النشاط التجاري (استبعاد البنوك التقليدية، التأمين
  غير التكافلي، الكحول، القمار، التبغ، لحم الخنزير، المحتوى للبالغين، والسلاح) + فرز
  النسب المالية الأربع (الدين، النقد والأوراق المالية، الذمم المدينة إلى القيمة السوقية
  < 33%، والدخل غير النقي إلى الإيرادات < 5%).
- **محرك تحليل فني**: SMA (20/50/200)، EMA (12/26)، RSI(14)، MACD(12,26,9)، Bollinger
  Bands(20,2)، اتجاه حجم التداول، مدى 52 أسبوع.
- **محرك تحليل أساسي**: مكرر الربحية، نمو الإيرادات، هامش الربح.
- **محرك توصيات مركّب**: يدمج النقاط الفنية (60%) والأساسية (40%) في توصية
  (شراء قوي / شراء / احتفاظ / بيع / بيع قوي) مع تفسير نصي بالعربية والإنجليزية.
- **أفضل التوصيات اليومية**: مسح متوازٍ لمجموعة أسهم مرشّحة، وترتيب المتوافقة شرعياً
  فقط حسب النقاط المركبة.
- **استعلام عن سهم محدد**: تقرير كامل (سعر، فحص شرعي، مؤشرات فنية، توصية) لأي رمز أمريكي.
- **اختبار خلفي (Backtesting)**: تشغيل استراتيجية النقاط الفنية على سنوات من البيانات
  التاريخية الحقيقية (بدون تحيّز معرفة مستقبلية) لمعرفة هل كانت ستربح فعلاً، لكل سهم أو
  على مجموعة الأسهم كاملة — قبل الوثوق بأي توصية بمال حقيقي.
- **لوحة تحكم عربية RTL احترافية** مع رسم بياني للسعر، شارات امتثال/توصية، وأشرطة نسب مرئية.

## البنية المعمارية

```
backend/
  app/
    config.py              إعدادات قابلة للتهيئة عبر متغيرات البيئة
    cache.py                طبقة تخزين مؤقت TTL بسيطة وآمنة للخيوط
    schemas.py               نماذج Pydantic لكل استجابات الـ API
    universe.py              قائمة الأسهم المرشحة للمسح اليومي
    data_provider.py         واجهة مزوّد بيانات + تنفيذ عبر yfinance (قابلة للاستبدال)
    shariah_screening.py     محرك الفرز الشرعي (نشاط تجاري + نسب مالية)
    technical_analysis.py    حساب المؤشرات الفنية من السلسلة السعرية
    scoring.py                تحويل المؤشرات إلى نقاط فنية/أساسية/مركبة
    recommendation_engine.py تجميع كل ما سبق في تقرير وتوصية نهائية
    backtesting.py            محاكاة تاريخية لاستراتيجية النقاط الفنية (بدون تحيّز مستقبلي)
    routers/                 نقاط API (stocks, recommendations, screening, backtest)
    main.py                   تطبيق FastAPI + تقديم الواجهة الأمامية
  tests/                      اختبارات pytest بمزوّد بيانات وهمي (بدون شبكة)
frontend/
  index.html / styles.css / app.js   لوحة تحكم عربية RTL بدون أي إطار عمل بناء (build-free)
```

**فصل الاهتمامات**: `MarketDataProvider` هو بروتوكول (interface)، والتنفيذ الفعلي
`YFinanceProvider` يجلب الأسعار والبيانات المالية من Yahoo Finance عبر مكتبة `yfinance`
مجاناً بدون مفتاح API، مع تخزين مؤقت (TTL cache) لتقليل عدد الطلبات. يمكن استبداله بمزوّد
بيانات آخر (مثل مزوّد مدفوع) دون تعديل أي منطق تحليل أو فرز.

## منهجية الفرز الشرعي

الفرز يتم ديناميكياً لكل سهم عند الطلب (وليس بالاعتماد على قائمة ثابتة)، على مرحلتين:

1. **فرز النشاط التجاري**: استبعاد الشركات التي يكون نشاطها الأساسي أعمالاً مصرفية
   تقليدية، تأمين تقليدي، خدمات ائتمان/أسواق مال/إدارة أصول تقليدية، تمويل عقاري بالفائدة،
   إنتاج كحول، قمار، تبغ، لحم خنزير، محتوى للبالغين، أو تصنيع أسلحة/ذخائر.
2. **فرز النسب المالية** (كل نسبة يجب ألا تتجاوز الحد المذكور):
   - الدين المُثقل بالفائدة / القيمة السوقية **< 33%**
   - النقد والأوراق المالية المدرة للفائدة / القيمة السوقية **< 33%**
   - الذمم المدينة / القيمة السوقية **< 33%**
   - الدخل غير النقي (فوائد وغيرها) / إجمالي الإيرادات **< 5%**

عند تعذّر الحصول على أحد البنود المالية اللازمة، تُصنَّف الحالة "**يتطلب مراجعة**" بدلاً من
افتراض الامتثال، حفاظاً على الدقة والشفافية. جميع الحدود قابلة للتهيئة في `app/config.py`.

## منهجية الاختبار الخلفي (Backtesting)

قبل الوثوق بأي توصية بمال حقيقي، يوفر التطبيق اختباراً خلفياً حقيقياً (وليس مجرد عرض
توضيحي) لمعرفة هل كانت استراتيجية النقاط الفنية ستربح فعلاً لو طُبّقت تاريخياً:

- **المكوّن الفني فقط**: يُختبَر جزء التحليل الفني من محرك التوصية (وليس المكوّن
  الأساسي/المالي)، لأن بيانات Yahoo المجانية للقوائم المالية التاريخية لا تسمح بإعادة
  بناء القيم الفعلية في كل تاريخ سابق دون تحيّز معرفة مستقبلية (look-ahead bias).
- **بدون تحيّز مستقبلي**: كل إشارة تُحتسب من بيانات متاحة حتى نهاية يوم التداول t فقط،
  وتُنفَّذ الصفقة بسعر **افتتاح** اليوم التالي (t+1) — وليس بسعر إغلاق يوم الإشارة نفسه.
- **مركز واحد فقط**: شراء بالكامل / بيع بالكامل، بدون رافعة مالية وبدون بيع على المكشوف
  (متوافق مع مبدأ عدم البيع على المكشوف في الاستثمار الشرعي).
- **غير محتسب**: العمولات، فروقات السعر (bid/ask spread)، والضرائب — فالنتائج الفعلية
  ستكون أسوأ قليلاً مما يظهر.
- **المقاييس**: العائد الإجمالي، معدل النمو السنوي المركب (CAGR)، أقصى تراجع
  (Max Drawdown)، نسبة الصفقات الرابحة، ومقارنة مباشرة بأداء "الشراء والاحتفاظ" لنفس
  السهم في نفس الفترة.
- **اختبار جماعي**: يمكن تشغيل الاختبار على مجموعة الأسهم المرشحة دفعة واحدة لمعرفة
  متوسط الأداء ونسبة الأسهم التي تفوقت فيها الاستراتيجية على الشراء والاحتفاظ.

> **مهم**: أداء تاريخي إيجابي في الاختبار الخلفي **لا يضمن** نتائج مستقبلية مماثلة.
> هذا الاختبار خطوة ضرورية قبل الثقة بأي استراتيجية، وليس ضماناً للربح.

## التشغيل محلياً

### المتطلبات
- Python 3.11+

### الخادم (Backend)

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

الواجهة الأمامية تُقدَّم تلقائياً من نفس الخادم على `http://localhost:8000/`،
وتوثيق الـ API التفاعلي متاح على `http://localhost:8000/docs`.

### الاختبارات

```bash
cd backend
python3 -m pytest -q
```

الاختبارات تستخدم مزوّد بيانات وهمياً (`FakeProvider`) فلا تحتاج اتصالاً بالإنترنت.

## مرجع API

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/health` | فحص صحة الخدمة |
| GET | `/api/stocks/{ticker}` | تقرير تحليل كامل (سعر، فحص شرعي، مؤشرات فنية/أساسية، توصية) |
| GET | `/api/stocks/{ticker}/history?days=180` | سلسلة سعرية مختصرة للرسم البياني |
| GET | `/api/screening/{ticker}` | تقرير الفحص الشرعي فقط |
| GET | `/api/recommendations/daily?limit=10&refresh=false` | أفضل التوصيات اليومية من الأسهم المتوافقة شرعياً |
| GET | `/api/backtest/{ticker}?initial_capital=10000` | اختبار خلفي للاستراتيجية الفنية على سهم واحد |
| GET | `/api/backtest/universe?limit=20` | اختبار خلفي مجمّع على مجموعة من الأسهم المرشحة |

## قيود معروفة

- بيانات yfinance عامة وقد تتأخر أو تنقص بعض البنود (خصوصاً دخل الفوائد المنفصل)، لذا
  يُعرض ذلك دائماً كملاحظة شفافة في التقرير بدل افتراض الامتثال.
- قائمة الأسهم المرشحة (`app/universe.py`) هي نقطة انطلاق للمسح اليومي فقط، وليست حكماً
  مسبقاً بالحلّية؛ الفرز الفعلي يُحتسب حياً في كل طلب.
- النماذج الفنية/الأساسية إرشادية وليست ضماناً لأي عائد أو أداء مستقبلي.
- الاختبار الخلفي يغطي المكوّن الفني فقط (انظر "منهجية الاختبار الخلفي" أعلاه)، ولا يحتسب
  تكاليف التنفيذ الحقيقية (عمولات، فروقات سعرية، ضرائب).
- لا يوجد حالياً أي ربط بمنصة وساطة أو تنفيذ آلي للصفقات — التطبيق أداة تحليل واختبار فقط،
  وأي قرار شراء أو بيع فعلي يبقى قراراً يدوياً بالكامل من المستخدم.
